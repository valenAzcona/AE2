# AE2 - Simulador de Procesos y Memoria

Proyecto correspondiente a la Actividad Evaluativa 2.

El sistema simula la administración de procesos, memoria y CPU mediante una planificación Round Robin, asignación contigua de memoria y eventos de Entrada/Salida.

## Tecnologías utilizadas

- TypeScript
- Node.js
- Vitest
- Git
- GitHub Actions

## Requisitos

Para ejecutar el proyecto se necesita:

- Node.js
- npm
